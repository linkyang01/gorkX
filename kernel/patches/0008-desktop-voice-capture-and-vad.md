# 0008 — desktop voice capture and STT VAD

- **Upstream base:** locked Grok Build `1.0.12` at `bc7f02eddd3d84085849dc19ed216f11c23b0571`, after patches `0001`–`0007`
- **Reason:** the desktop ACP adapter previously used `VoiceConfig::default()` and the STT server's default voice gate. That ignored the App's effective endpoint/voice settings and could classify a valid, quiet macOS input as no speech. The desktop launcher also now selects the in-process capture backend so the authorized gorkX responsible-process chain is not split by the macOS helper subprocess.
- **Affected behavior:** native ACP voice only. It uses the App-resolved voice endpoint, carries the Settings → Voice preferred recognition language for the next capture, sends `vad_threshold=0` for desktop push-to-talk, and keeps the existing explicit start/stop/shutdown and 10-second no-speech safety limit. Automatic detection is the default; Chinese is model-detected because xAI documents `language` as a formatting option and does not list `zh` in its formatting catalog. Device selection remains the OS default input device; no browser speech path or background recording is added.
- **Risk:** disabling server VAD means the existing PTT release is the utterance boundary and silence is bounded by the existing watchdog. In-process macOS capture trades the helper's lower long-lived memory footprint for a reliable App TCC/process boundary while voice is active.
- **Regression command:**
  `scripts/verify-grok-kernel-patches.sh && GORKX_BUILD_TARGET=aarch64-apple-darwin scripts/build-grok-kernel.sh /private/tmp/gorkx-grok-voice && node scripts/verify-grok-acp.mjs /private/tmp/gorkx-grok-voice --voice-controls`
- **Manual acceptance:** launch the rebuilt gorkX.app, choose the preferred recognition language (automatic detection is recommended), confirm the selected macOS input device, start native voice, speak one short phrase, stop, and verify the final transcript enters the editable draft without auto-send. A clean single-phrase result and a manual-send round are separate H3 evidence; they are not inferred from the settings control or protocol tests.
